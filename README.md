# منصة السادس الإعدادي

تطبيق تعليمي لدراسة اللغة الإنكليزية للصف السادس الإعدادي وفق المنهج العراقي الرسمي.

## التشغيل محلياً

**المتطلبات:** Node.js

1. تثبيت الحزم:
   `npm install`
2. تشغيل التطبيق:
   `npm run dev`
3. افتح المتصفح على:
   `http://localhost:3001`

## الميزات
- بنك أسئلة وزارية
- مراجعة القواعد
- دروس من الوحدات المختلفة
- اختبارات قصيرة ومتابعة تقدم الطالب
- ملاحظات وفخاخ وزارية
